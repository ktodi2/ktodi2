## RAW NOTES (being consolidated)
- Flex Structure FY24-28 (updated 04/2025): Program Area 2 FOI required; project types incl Revenue Cycle Mgmt, Chargemaster Review, Billing & Coding Education; official intermediate outcomes "Reduced percentage of claims denied", "Increase percentage of denied claims re-billed", "Improved clean claims rate"; long-term "days net revenue in AR" (CAHMPAS). https://www.ruralcenter.org/sites/default/files/FY24-FY28%20Flex%20Program%20Structure.pdf
- HRSA: Flex serves 1,360 CAHs; SORHs carry out Flex. https://www.hrsa.gov/rural-health/grants/rural-hospitals/flex
- FY2019 NOFO: ~ $27M total, ~45 cooperative agreements (per KHI spotlight) https://www.khi.org/wp-content/uploads/2025/11/FORHP-Grant-Spotlight-Medicare-Rural-Hospital-Flexibility-Program-Web.pdf ; FY2026 HHS budget proposed eliminating Flex (same source).
- ND: CAH Subcontract Program, $40,000 pot; menu: coding/billing chart audit, CDM review/scrub, 340B audit, RCM, service line; 2024 awards $11,550 e.g. SMP Health St. Aloisius revenue cycle review. https://ruralhealth.und.edu/projects/flex/funding-programs/awards ; https://www.ruralhealthinfo.org/funding/2253 (contact Holly Long). 2025 cost report review by Eide Bailly for 4 CAHs; Flex paid 13 CAHs to attend Eide Bailly CAH conference. https://ruralhealth.und.edu/projects/cah-quality-network/newsletter/2025-fall ; .../2025-spring
- MN: Flex Billing & Coding Training Grant RFP: up to $15,000/yr to an ORGANIZATION (vendor/trainer) to train CAH/RHC staff; goals: reduce % claims denied, increase % denied claims resubmitted. MDH Flex = $1,049,465/yr. 77 CAHs. https://www.health.state.mn.us/facilities/ruralhealth/funding/grants/docs/flexbctrfp.pdf ; FAQ says SHIP can cover hospital's own billing/coding training.
- WI: WORH Flex "D2H Finance Analysis Grant 2025-26" up to $15,000 per hospital to hire consultant; scope incl revenue cycle improvement, charge capture/coding/billing effectiveness; priority by Financial Distress Index. https://worh.org/wp-content/uploads/2025/12/D2H-Finance-Analysis-Grant-2025-26.pdf
- MT: Flex grantee DPHHS OIG; MHREF (MHA foundation) primary contractor since 1999; Flex funds NOT sub-granted to hospitals, delivered as programs. Revenue Cycle Intensive: 32 CAH staff from 17 facilities; Revenue Cycle/RHC workshops Fall 2025. https://mtpin.org/wp-content/uploads/2025/05/2025-Quality-Update.pdf ; https://mtpin.org/wp-content/uploads/2022/03/Intro_Flex_22.pdf
- MT RHTP application: state to facilitate GPO/vendor access for back-office incl revenue cycle management; "Vendors offering favorable rates to leverage the latest AI enabled technology... prioritized". https://bloximages.chicago2.vip.townnews.com/helenair.com/content/tncms/assets/v3/editorial/5/40/5403a343-1f27-5bcc-883c-89701ab34573/69408c3a5488c.pdf.pdf
- KS: KDHE SORH; contracted KRHOP to administer Flex; 82 CAHs; KDHE RFP EVT0010173 for SHIP+Flex admin/TA contract 7/2025-6/2030. https://www.kdhe.ks.gov/311/Medicare-Rural-Hospital-Flexibility-Prog ; https://www.highergov.com/sl/contract-opportunity/ks-ship-and-flex-programs-45584882/
- TX: SORH at Texas Dept of Agriculture; FY2026 SHIP max per hospital $13,528 (TX RFGA). https://texasagriculture.gov/Portals/0/Publications/ER/SORH/SHIP/2026_-_SHIPRFGA1.5.2026.pdf ; HHSC Rural Hospital Grant Program 2024: $450k to TORCH for data platform (62 hospitals). https://www.hhs.texas.gov/sites/default/files/documents/rural-hospital-grant-program-report-2024.pdf
- SHIP: allowable = hardware, software, training in VBP/ACO/PB-PPS; "Revenue Cycle Management training" allowable; "ICD-10 billing & coding trainings to reduce errors and improve reimbursements"; subscriptions allowed for listed categories; EHR subscription allowable per MN FAQ. https://www.ruralcenter.org/programs/ship/allowable-investments/search-tool ; https://www.ruralcenter.org/frequently-asked-questions ; https://www.health.mn.gov/facilities/ruralhealth/funding/grants/docs/shipfaq.pdf
- SHIP search tool (fetched 2026-09-24): Software "allowable expense" if supports SHIP-approved category (updated Dec 2025); Subscriptions "generally allowable" (updated May 2026) with examples: EMR/EHR, ICD-10/11 software, price transparency, S-10 cost reporting, 340B software, cybersecurity; "Contractors, Consulting, and Reviews" UNALLOWABLE incl "Vendor Consultation" (excl HCAHPS, chargemaster review); "Hospital Finance Assessments" unallowable; "Revenue Cycle Management training" and "ICD-10 billing & coding trainings to reduce errors and improve reimbursements" allowable under PB/PPS; recurring payments unallowable (definition); subscriptions that "happen to include" a SHIP item should be avoided. Denial/appeals software NOT named anywhere. https://www.ruralcenter.org/programs/ship/allowable-investments/search-tool ; ?page=1
- SHIP national: FY2023 $20.7M to 46 states, 1,660 hospitals, ~$13,312 each; per-state counts (MT 46, ND 36, MN 61, KS 94, TX 118, WI 66, GA 56...). https://www.govinfo.gov/content/pkg/CMR-HE20_9000-00198896/pdf/CMR-HE20_9000-00198896.pdf ; FY2026 est max per hospital $13,528 (MN NOGO https://www.health.mn.gov/facilities/ruralhealth/funding/grants/docs/shipnogo.pdf ; TX RFGA). HRSA: ~1,600 hospitals https://www.hrsa.gov/rural-health/grants/rural-hospitals/ship
- TASC (ruralcenter.org, Duluth MN): supports state Flex programs; ~600 TA requests/yr. https://www.ruralcenter.org/programs ; RCM Best Practices Guide (DRCHSD, BKD, updated July 2023) https://www.ruralcenter.org/resources/revenue-cycle-management-best-practices-guide
- RHSP (Rural Hospital Stabilization Program): HRSA FY2024 $3,930,405; ~$11.8M over 3 yrs to Rural Health Resource Center https://www.hrsa.gov/rural-health/grants/rural-hospitals/fy24-awards ; first 8 hospitals June 2025 (per Spencer Fane https://www.spencerfane.com/insight/rural-hospital-stabilization-program-update/); FOA + "vendor demonstrations, purchasing guidance"; funds equipment/software for service lines https://www.ruralcenter.org/programs/stabilization/faq ; FAQ lists other TA programs: DRCHSD, USDA Rural Hospital TA, REH TA Center, TTAP, Appalachian Region Healthcare Support Program, Northern Border Region TA.
